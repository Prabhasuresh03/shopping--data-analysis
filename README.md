# Shopping Data Analysis

## 📊 Project Overview

This project analyzes customer shopping data using **Python and SQL** to understand customer behavior, purchasing patterns, and shopping trends.

## 🎯 Objectives

- Analyze customer shopping behavior
- Identify popular products and categories
- Understand customer purchase patterns
- Analyze sales and revenue-related trends
- Generate useful insights from the dataset

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Google Colab
- GitHub

## 📁 Dataset

The project uses a customer shopping dataset containing information such as:

- Customer details
- Product categories
- Purchase amounts
- Shopping frequency
- Payment methods
- Discounts
- Customer ratings

## 🔍 Analysis Performed

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Customer behavior analysis
- Product and category analysis
- Purchase and sales analysis
- Data visualization
- SQL-based data analysis

## 📓 Project File

- `Customer_Shopping_Analysis.ipynb` – Python and SQL analysis notebook

## 📌 Conclusion

The analysis provides insights into customer shopping behavior and purchasing trends that can help in making data-driven business decisions.
